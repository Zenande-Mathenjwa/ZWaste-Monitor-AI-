## Guidelines

Design the app UI following IBM Carbon Design System principles. Implement a strict 16px grid with 2x grid (32px) for layouts and consistent spacing scale: 2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64px. Use Carbon's four-layer model: base background (#ffffff), layer-01 (#f4f4f4), layer-02 (#ffffff), layer-03 (#f4f4f4). Primary palette uses cool gray/neutral scale with IBM Blue (blue if not specified) as primary action color, plus semantic colors: error (#da1e28), warning (amber), success (green). Components must be angular with sharp corners (0px) or minimal rounding (2px max). Buttons have three sizes (32px, 40px, 48px height) with 16px horizontal padding, using solid fills for primary, ghost for secondary, with clear focus states (2px offset outline). Typography uses IBM Plex Sans with controlled scale: 12, 14, 16, 20, 28, 36, 54px. Data tables are fundamental - use zebra striping on hover, sortable column headers with arrows, inline actions, and expandable rows. Forms use consistent 40px input heights with labels above or inline, red error states below fields, and helper text in gray. Include Carbon's signature inline notifications, modal patterns, and side panels. Implement token-based spacing throughout. The interface should feel systematic, predictable, accessible (WCAG AA), and optimized for productivity - perfect for enterprise dashboards, data analysis tools, and complex business applications
